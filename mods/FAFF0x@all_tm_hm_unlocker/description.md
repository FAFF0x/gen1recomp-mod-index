# All TM & HM Unlocker

A standalone quality-of-life mod for Gen1Recomp.

## Features

- Unlocks every Generation I TM and HM automatically.
- Stocks every TM to **99**.
- Adds one copy of every HM.
- Works with new games and existing saves.
- Replenishes consumed TMs to 99 the next time the game is loaded.
- Expands the bag capacity to 255 item slots so all machines fit safely.
- Preserves the original Pokémon TM/HM compatibility and learnsets.
- Compatible with Modern Bag; no dependency is required.

## Installation

Place the `all_tm_hm_unlocker` folder in the Gen1Recomp mods directory and enable it from the mod menu.

Load a save or begin a new game. The TM and HM collection is added automatically when the game becomes ready.

## Notes

- Existing quantities above the target are never reduced.
- Story flags, badges, field-move permissions, and map progression are not changed.
- Owning an HM does not bypass badge requirements for using its field move.
