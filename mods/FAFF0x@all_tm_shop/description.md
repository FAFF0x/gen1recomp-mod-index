# Universal Free TM Shop

A standalone quality-of-life mod for Gen1Recomp.

## Features

- Every Poké Mart clerk offers three choices:
  - **NORMAL SHOP**
  - **TM SHOP**
  - **LEAVE**
- The normal shop keeps the location's original items and prices.
- The dedicated TM Shop contains every Generation I TM, ordered from TM01 to TM50.
- Every TM costs **¥0**.
- The list also shows the move contained in each TM.
- Left/Right jumps one page and holding Up/Down scrolls quickly.
- You may buy any quantity up to the normal stack limit of 99.
- HMs are not sold.
- Bag capacity is expanded to 255 slots.
- TM sell value is zero, preventing an infinite-money exploit.
- Compatible with Modern Bag.

## Installation

Remove or disable `all_tm_hm_unlocker`, then place the `all_tm_shop` folder in the Gen1Recomp mods directory and enable it.

Restart the game completely. Enter any Poké Mart and speak to the clerk.

## Notes

- This mod does not add TMs automatically.
- Pokémon keep their original TM compatibility.
- Badge and story progression are not modified.
- Existing TMs already in the Bag are preserved.
