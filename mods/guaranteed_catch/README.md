# Guaranteed Catch

A Gen1Recomp gameplay mod that makes every registered Poke Ball catch the target successfully.

## What it changes

- Poke Ball: 100%
- Great Ball: 100%
- Ultra Ball: 100%
- Safari Ball: 100%
- Master Ball: unchanged at 100%
- Ball types registered by other mods: 100%, when loaded before this mod

The result ignores current HP, status conditions and the species catch rate. The Ball is still consumed normally, and the standard throw/capture animation still plays.

## Installation

Import the ZIP through the MODS screen, enable **Guaranteed Catch**, then fully restart Gen1Recomp.

The mod is intentionally assigned a very high load priority so it applies after most Ball-content mods. It does not require engine-internal permissions.

## Compatibility

Compatible with Catch Helper: its displayed P/G/U probabilities become 100% because it reads the merged `autoCatch` flag.
