# Trade Evolution Fix

Mod nativa Lua per Gen1Recomp.

Converte le quattro evoluzioni tramite scambio della prima generazione in evoluzioni al livello 40:

- Kadabra → Alakazam
- Machoke → Machamp
- Graveler → Golem
- Haunter → Gengar

## Come funziona

L'evoluzione viene proposta quando il Pokémon raggiunge o supera il livello 40 tramite un aumento di livello. Se installi la mod quando il Pokémon è già al livello 40 o superiore, salirà di forma al successivo aumento di livello.

La mod modifica soltanto le righe di evoluzione con metodo `TRADE`. Eventuali altre evoluzioni aggiunte da mod caricate prima vengono conservate.

## Installazione

Importa direttamente il file ZIP dalla scheda MODS del launcher di Gen1Recomp. Verifica che la mod sia abilitata, poi riavvia completamente il gioco.

## Compatibilità

- Mod API: 2
- Gen1Recomp: versioni inferiori alla 2.0.0
- La mod modifica dati rilevanti per le lotte/scambi in link; entrambi i giocatori dovrebbero usare la stessa configurazione.
